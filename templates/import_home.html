Fill in one row for each past complaint, up to {{ max_rows }}. Only Factory, Issue date, Complaint from and Complaint type must be filled in; leave a cell empty if the old log did not have it.

  • Each complaint gets a platform reference (for example FA/2026/0007) in date order, so the running numbers carry on. The number it had in the old log is kept.
  • Its stage comes from the dates: a closing date makes it Closed, a reply date Customer Response Sent, any investigation or decision PIC investigation, otherwise Submitted. A complaint that is still open starts its reminders at the import.
  • A reply date or a closing date needs Valid or invalid. No emails are sent.
